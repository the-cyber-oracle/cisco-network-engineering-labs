**Stop memorising commands. Start understanding networks.**

Welcome to the Cisco Network Engineering Labs, an open practical networking initiative created by **Ayomide Oyedele (The Cyber Oracle)**.

This repository contains a structured collection of Cisco networking demonstrations, Packet Tracer exercises, configuration guides, troubleshooting scenarios and practical challenges.

The goal is simple: make practical networking knowledge accessible to aspiring network engineers, CCNA candidates, IT professionals and cybersecurity enthusiasts.

Whether you're configuring your first Cisco router or troubleshooting a multi-router enterprise topology, this repository is designed to help you develop the knowledge and confidence to work with network infrastructure.

---

## Why This Project?

Networking is one of those disciplines where understanding the theory is only half the journey.

You can memorise OSPF commands and still struggle to establish an adjacency. You can understand VLANs and still fail to configure inter-VLAN routing. You can learn DHCP and still spend hours troubleshooting why a client isn't receiving an IP address.

That's why this project focuses on practical implementation.

We configure. We test. We troubleshoot. We deliberately introduce faults. Then we investigate and understand what went wrong.

**Every configuration should have a reason. Every result should be verified.**

## How to Use This Repository

**1. Install Cisco Packet Tracer**

Download Packet Tracer through Cisco Networking Academy's official learning platform.

**2. Clone this repository**

```bash
git clone https://github.com/YOUR-USERNAME/cisco-network-engineering-labs.git
```

**3. Navigate to an episode**

Choose a topic from the learning roadmap and open its folder.

**4. Download and open the lab**

Open the provided `.pkt` file in Cisco Packet Tracer, where available.

**5. Follow the configuration guide**

Read the instructions, understand the topology and implement the configuration.

**6. Verify your results**

Use the supplied verification commands and connectivity tests.

**7. Attempt the challenge**

Complete the additional exercise without looking at the solution first.
